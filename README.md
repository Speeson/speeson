#### My Agentic Development Workflow

**Specification → Planning → Agent Delegation → Implementation → Testing → Deploy Impact → Review → Release**

- **Spec-Driven Development (SDD):** Structured requirements, technical specifications, acceptance criteria, and implementation plans.
- **Agents & Subagents:** Task delegation and coordination across development, investigation, testing, and review.
- **AGENTS.md:** Persistent repository instructions, architecture conventions, execution boundaries, and coding standards.
- **Hooks:** Event-driven automation for development notifications, scripts, and validation.
- **Railways & Golden Paths:** Repeatable execution paths that guide agents through controlled development workflows.
- **Harness Engineering:** Agent environments, context management, tool integration, constraints, and feedback loops.
- **Deploy Impact:** Change-impact analysis covering affected components, tests, migrations, and deployment requirements.
- **Quality Gates:** Automated testing, linting, build verification, and human-reviewed delivery.

These practices are applied to real multi-component projects, coordinating changes across **frontend, backend, desktop applications, game addons, databases, and cloud infrastructure**.
